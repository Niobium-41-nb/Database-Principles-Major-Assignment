# 前端开发手册（HTML + CSS + JS）

```text
frontend/
├── index.html              # 首页
├── css/
│   ├── style.css           # 全局样式
│   ├── user.css            # 用户相关样式
│   ├── problem.css         # 题目相关样式
│   └── contest.css         # 比赛相关样式
├── js/
│   ├── main.js             # 主逻辑和工具函数
│   ├── user.js             # 用户功能
│   ├── problem.js          # 题目功能
│   ├── contest.js          # 比赛功能
│   └── submission.js       # 提交记录功能
├── pages/                  # 子页面（可选）
│   ├── user.html
│   ├── problem.html
│   └── contest.html
└── assets/                 # 静态资源
    ├── images/
    └── icons/
```
