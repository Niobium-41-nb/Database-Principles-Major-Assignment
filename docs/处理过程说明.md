## 2. Hack随机处理 - 判定表

```mermaid
    L --> N
    M --> N
    E --> N
```

### 2.2 Hack验证流程判定表

| 步骤 | 验证条件 | 失败动作 | 成功动作 |

| 2 | 目标提交存在 | 返回"提交记录不存在" | 继续验证 |

## 3. 完整评测系统随机流程

### 3.1 完整随机评测系统

```mermaid
flowchart TD

    K --> M[❌ Wrong Answer 25%]
    K --> N[⏰ Time Limit 8%]
    K --> O[💾 Memory Limit 8%]
    K --> P[🔥 Runtime Error 8%]
    K --> Q[📋 Presentation Error 4%]
    K --> R[🌀 Idleness Limit 4%]
    K --> S[🎯 Partial Solution 2%]
    
    L --> T[💾 更新评测结果]
    M --> T
    N --> T
    O --> T
    P --> T
    Q --> T
    R --> T
    S --> T
    J --> T
```

### 3.2 随机数生成逻辑

```mermaid
flowchart LR
    A[🎲 随机数生成器] --> B[📊 Python random.choices]
    
    B --> C[⚖️ 权重配置]
    C --> D[verdicts: 结果列表]
    C --> E[weights: 权重列表]
    
    D --> F['Accepted', 'Wrong Answer', ...]
    E --> G[35, 25, 8, 8, 8, 6, 4, 4, 2]
    
    F --> H[🔀 随机选择]
    G --> H
    
    H --> I[🎯 选定评测结果]
    I --> J[📝 记录到数据库]
```

## 4. 随机处理代码实现

### 4.1 评测随机化代码流程

```mermaid
flowchart TD
    A[submissions.py] --> B[submit_solution函数]
    B --> C[📝 插入提交记录]
    C --> D[🎲 随机结果生成]
    
    D --> E[📋 定义结果列表]
    E --> F[verdicts = <br>'Accepted', 'Wrong Answer',<br>'Time Limit Exceeded', 'Memory Limit Exceeded',<br>'Runtime Error', 'Compilation Error',<br>'Idleness Limit Exceeded', 'Presentation Error',<br>'Partial Solution']
    
    D --> G[⚖️ 定义权重列表]
    G --> H[weights = <br>35, 25, 8, 8, 8,<br>6, 4, 4, 2]
    
    D --> I[🔀 random.choices调用]
    I --> J[verdict = random.choices<br>verdicts, weights=weights]
    
    J --> K[🎯 获得随机结果]
    K --> L[💾 更新提交记录]
    L --> M[📊 返回用户结果]
```

### 4.2 Hack随机化代码流程

```mermaid
flowchart TD
    A[hacks.py] --> B[submit_hack函数]
    B --> C[🔍 验证Hack资格]
    C --> D[✅ 资格验证通过]
    
    D --> E[💾 插入Hack记录]
    E --> F[🎲 随机Hack结果]
    
    F --> G[🪙 random.choiceTrue, False]
    G --> H{随机结果}
    
    H -->|True| I[🎉 Hack成功]
    H -->|False| J[💥 Hack失败]
    
    I --> K[📈 Rating调整]
    K --> L[🔼 攻击者 +50]
    K --> M[🔽 防御者 -50]
    
    J --> N[➡️ Rating不变]
    
    L --> O[💾 更新Hack记录]
    M --> O
    N --> O
    
    O --> P[📋 返回Hack结果]
```
